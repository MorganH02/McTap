# MC Tap

**Live site → https://morganh02.github.io/McTap/**

Website for MC Tap, a tavern at 303 Pacific Street, Monroe Center, Illinois.
Half-pound burgers, cold beer, and a stool with your name on it.

Plain HTML, CSS and JavaScript. No build step, no framework, no dependencies.

## Pages

| File | What it is |
| --- | --- |
| `index.html` | Home — menu, photos, hours, directions |
| `order.html` | Pickup ordering with substitutions |

Both are currently self-contained: the CSS, JavaScript and photos are embedded
directly in each file so the site could be published from a phone. The split
version (separate `assets/` and `images/` folders) will replace these.

## Features

- Open/closed badge that calculates live in Monroe Center time, including
  closing times after midnight
- Pickup ordering with per-item substitutions, a cart and pickup-time slots
- Structured data so Google can read the address, phone number and hours
- Responsive, keyboard accessible, works down to small phone screens
